# World Lab

An executable spatial index of independent simulation laboratories.

**Live:** https://bonoj.github.io/world-lab/

World Lab gives several projects a common physical substrate without forcing them into one shared simulation. Each lab remains authoritative for its own behavior. The vestibule exposes only enough project-specific behavior to make the labs physically distinguishable before entering them.

## Current labs

- **[Foundry](https://bonoj.github.io/Foundry/)** — retrieves beyond its world.
- **[Six Cities](https://bonoj.github.io/SixCities/)** — exchanges across its world.
- **[Vertical Accretion](https://bonoj.github.io/VerticalAccretion/)** — builds access on its world.
- **[Orbital Construction](https://bonoj.github.io/OrbitalConstruction/)** — lives around its world.

A fifth presence remains deliberately unassigned.

The relationships are intentionally asymmetric. Vertical Accretion produces persistent loose spoil; Foundry drones retrieve it. That interaction survives because existing behaviors compose cleanly. The other labs are not connected merely to make the world busier.

> Composition is evidence, not content.

## Interaction

Tap a presence to foreground and inspect it. Assigned projects expose **ENTER LAB** and **GITHUB** actions. Dismissing a presence restores the previous observer state, and browser Back returns to the focused inspection state after visiting a lab.

The common white marble is the substrate. Project identity is earned through the smallest physical behavior or construction vocabulary supported by the source lab, not through labels, miniature scenery, or invented connective machinery.

## Development

The executable is the primary evidence.

World Lab develops through a human/model loop:

```text
human intention
→ smallest executable hypothesis
→ spatial experience
→ perceptual evidence
→ correction
→ repeated evidence
→ semantic / architectural promotion
→ next hypothesis
```

Ordinary implementation decisions belong to the implementation pass. Human inspection determines what earns permanence.

The current semantic interpretation, boundaries, architecture, and non-claims live in **[SEMANTIC_SURFACE.md](./SEMANTIC_SURFACE.md)**. Implementation archaeology and runtime diagnostics remain embedded in `index.html` where they can travel with the executable.

## Repository

`index.html` is the self-contained World Lab executable and GitHub Pages entry point. Accepted heads are published from `main`.

Transport, deployment, and connector machinery are infrastructure, not the conceptual center of the project. They should not dictate artifact architecture.
